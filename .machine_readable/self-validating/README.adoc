= echo-types K9 components and source templates

`examples/project-metadata.k9.ncl` is an active Kennel data component. Its
`fv` identity and UUID8 come from gv-clade-index revision
`2cfabd15d6cb966ed369ee13aa7174b960f45abd`; its version describes the metadata
component, not a claimed project release.

Files ending `.k9.ncl.in` are inert templates. They are not installed K9
components, are never executed, and are excluded from active-component checks.
In particular the unsigned Hunt setup example remains an uninstantiated
example. Do not treat its signature placeholders as signatures or copy it to
an active component without satisfying the current K9 contract.

Active operational declarations live in `../contractiles/`; their probes
refer to real root recipes. The old duplicate `svc/k9` mirror is retired.

The normative source is standards `1-formats/k9/spec/K9-CONTRACT-SPEC.adoc`
and `spec/contract/k9_contract.ncl`, pinned by `tools/check-metadata.sh`.
Run that script from the repository root with Bun and Nickel available.
