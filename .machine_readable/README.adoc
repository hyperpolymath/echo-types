== Operational declarations

`contractiles/<verb>/<verb>.k9.ncl` holds each verb declaration; its adjacent
`<verb>.ncl` supplies the canonical schema and run-policy data. Root Just
recipes execute checks. These Nickel records do not implement a contractile
CLI, execute their probe strings, or grant external publication authority.

`self-validating/` holds one active Kennel metadata example and inert `.in`
templates. The old `svc/k9` mirror was retired rather than maintained twice.
The root `coordination.k9.ncl` is a pure pointer to canonical session protocols.

== Validation

[source,bash]
----
ECHO_STANDARDS_DIR=/path/to/pinned/standards bash tools/check-metadata.sh
----

Bun, Nickel and Bash are required. The script checks the standards revision,
runs the current native DEED grammar validator and K9 `--strict` validation,
and rejects retired metadata and identity drift. Missing semantic tooling is
a failure. The frozen Python DEED validator is not used. This validation does
not run declared probes and does not award certification or an assurance grade.
