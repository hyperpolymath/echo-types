= Integration pointers

Root `echo-types_chora.deed` records the source-backed ecosystem relationships.
`absolute-zero` supplies CNO definitions; `EchoTypes.jl` is an executable
finite-domain companion. The ordinal lane is maintained separately in
`ordinal-notation`; no ordinal work is authorized by these metadata records.
No connector, credential, deployed service, or external write access is implied.
