== Statement correspondence

The comparison was made by reading: each Rocq and Lean definition restates
the Agda definition it mirrors, clause by clause.

The definitions behind them:

* `Echo f y = Σ A (λ x → f x ≡ y)` (`Echo.agda`). Rocq writes it as
  `{x : A & f x = y}` (`sigT`), Lean as `(x : A) ×' (f x = y)` (`PSigma`).
* `EchoS enum f y n = Σ ℕ (λ k → (k < n) × (f (enum k) ≡ y))`
  (`EchoSearch.agda`). Both targets use a proof-relevant Σ over `k` with the
  same two components.
* `bounded-search-is-decidable` recurses structurally on the budget, and its
  successor step tests the new top index `n` first, then recurses. The
  targets recurse the same way and in the same order, so the `decided`
  equation computes to the same witness. The Agda comment notes this is one
  comparison, not an ascending walk.
* `EchoC` at `stepCostAlgebra = (ℕ, 0, _+_, _≤_, …)`: `Cost stepCostAlgebra`
  unfolds to `Σ A (λ x → (f x ≡ y) × (cost x ≤ c))`. The targets restate
  that instance directly, not the generic `CostAlgebra` record. The generic
  record and its laws are not part of these headlines.
* `search-steps = suc`; `count-up-search-to-cost` re-pairs, because `k < n` is
  `suc k ≤ n` definitionally. This holds in all three systems: stdlib `_<_`;
  Rocq `lt n m := S n <= m`; Lean `Nat.lt n m := Nat.le (n+1) m`.
* `EchoDec f y = Dec (Echo f y)`; `search-to-dec s = yes (echo-search-forget s)`.
* `CEcho`, `_≤a_` (15 Hasse pairs) and `degrade-access` are restated in full,
  case for case.

== Residual differences and assumptions

These do not change what the headlines state about this example, but they
are differences between the systems and are listed as the policy requires.

. *Identity type.* Agda's `_≡_` is used under `--without-K`. Rocq's `eq` lives
  in `Prop`, with no UIP axiom assumed. Lean's `Eq` lives in `Prop` with
  definitional proof irrelevance, so K holds in Lean. Every proof here is a
  closed computation (`refl` / `reflexivity` / `rfl`) or a re-pairing, so
  none of them uses K. The Lean leg is still checked in a strictly stronger
  theory.
. *Order and decision types.* Agda's `_<_` is a data type in `Set`; in Rocq
  and Lean it is a `Prop`. Agda's stdlib `Dec` is a record (`does`/`proof`);
  the targets use a local `yes`/`no` inductive with the same two cases.
  Decidable equality on ℕ is stdlib `_≟_` in Agda, a `decide equality` term
  in Rocq, and `Nat.decEq` in Lean.
. *Universes.* Agda is universe-polymorphic with `Lift` padding in `CEcho`.
  Rocq uses `Type` with template polymorphism; Lean uses `Type u` with
  `PUnit`. Both targets use the unit type where Agda uses `Lift (a ⊔ b) ⊤`.
. *Scope.* The `CostAlgebra` laws (`≤-refl`, `≤-trans`, `+-identityˡ`,
  `+-mono-≤`) are not restated, because no headline in this module depends
  on them. They are Agda-only facts for this theorem.

* Legs affected: Rocq and Lean, for this theorem.
