== Scope and release rule

The owner authorized local implementation, then explicitly authorized pushes,
pull requests and appropriate merges on 2026-11-06. This supersedes the audit's
initial read-only and subsequent local-only phases. Ordinal mathematics remains
excluded; the three residual ordinal source files are unchanged.

This ledger distinguishes source corrections, executed checks, external service
results and unresolved decisions. A configured scanner is not a passing scan;
an unsupported language is not clean coverage. No certification or numerical
stability score is asserted. The six bounded mathematical follow-up packets in
link:2026-11-06-foundation-decisions.adoc[the foundation decisions] remain research
work; repository setup does not discharge them.
