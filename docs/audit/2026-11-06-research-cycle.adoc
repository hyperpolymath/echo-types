== Mathematical decisions and checked contracts

[cols="1,3,3",options="header"]
|===
|Track |Implemented contract |Limit of the result
|Finite minimal residue
|`EchoFiniteResidue.ExactRecovery` supplies a total decoder of the actual
retained pair and a source-value round trip. Recovery forces residues to
separate distinct sources in one observation fibre. An injected family of
`n` such sources and residue alphabet `Fin k` imply `n ≤ k`.
|The representation class is finite alphabets; cost is alphabet cardinality.
The family need not enumerate the entire fibre. This is the standard finite
pigeonhole argument, not a bit/entropy/physical-cost bound or a reconstruction
of equality witnesses. The constant observation on `Fin n` attains the bound
by retaining the source; no uniform optimum for arbitrary observations is claimed.
|Consumption
|`EchoResidueProtocol` gives an indexed sequential transition/trace system
for the existing holding/spent API. Spent traces have zero reversals; every
valid trace has at most one. Reversing agrees with both `takeForReverse`
and the state returned by `consume`. Two-reversal traces are refuted.
|A single authoritative state trajectory is an explicit assumption. Arbitrary
idle steps are permitted, but no rearming or unrelated state mutation is
specified. Pure Agda values remain duplicable. Runtime alias prevention,
linear typing, heap ownership, concurrency, progress and refinement remain open.
|Composition and tropical measurement
|`Echo.Measure.Composition.CompositionalMeasure` uses standard-library lawful
source/target monoids and a monoid homomorphism. List length preserves append
and units. Equal costs can still hide different evidence and prevent recovery.
A constant-one ordered measure and its no-homomorphism theorem separate
monotonicity from additive unit preservation.
|This is an additional measurement contract, not a resource structure on Echo,
a graded (co)monad or a cross-language translation. No source monoid laws follow
from measured equalities alone. Extended tropical carriers, order variance,
grade tensor/unit, infinity and coherence must be supplied separately.
|F1: source-preserving comparison
|`EchoSourcePreservingComparison` characterizes pointwise equality of
`f,g : A → B` by a source-preserving forward fibre map and constructs
both fibre maps with inverse laws from that pointwise equality.
|Unrestricted fibre equivalences do not imply this conclusion. There is
no equality of functions obtained by global function extensionality.
|F2: CNO packaging
|`EchoCNOPackaging` packages logical implications among native nullity,
`IsCNO p`, same-program certified Echo and source-preserving native state
maps; certificates compose.
|These are logical equivalences, not equalities of proof records or inverse
laws on relation witnesses. The pinned native evaluator is total and its
energy model is zero. No physical reversibility result is added.
|===

The finite bound imports the existing standard-library theorem
`Data.Fin.Properties.injective⇒≤`. The compositional example imports
`Data.List.Properties.length-isMonoidHomomorphism`. Reusing these standard
constructions is deliberate. Distinguishing sources, retained evidence,
observable costs and operational permissions is the useful design boundary.

The old natural-number min-plus comment in `Echo/Measure/Examples.agda`
is corrected: `min` on natural numbers has no additive identity. The
existing example remains an order-only finite-cost measurement; a unital
min-plus semiring needs an appropriate extended carrier and its laws.
