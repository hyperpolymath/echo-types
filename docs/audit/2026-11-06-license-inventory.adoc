== Owner decision — 2026-11-06

The owner answered the question about future documentation policy with
`cc-by-sa-4.0 for docs and mpl-2.0 for code`, and requested per-file notices.
The selected identifiers are `CC-BY-SA-4.0` and `MPL-2.0`.

* New original prose documentation uses `CC-BY-SA-4.0`.
* New original code, configuration and scripts use `MPL-2.0`.
* Each new file carries the appropriate `SPDX-License-Identifier` and accurate
  `SPDX-FileCopyrightText`, in the format's comment syntax. A neighbouring
  `<filename>.license` sidecar serves formats that cannot contain comments.
* Edits to existing files retain their recorded notices and third-party
  attribution. A change to an existing file's licence requires a separately
  scoped record of authority and affected paths. This answer to a prospective
  policy question does not authorize an automatic rewrite of historical files.
* `LICENSE-docs`, other legal texts, the nine-file ruling, existing leading
  SPDX notices and the archived audit bytes are retained. The two missing
  declarations identified above remain explicit reconciliation work.

The current-policy pointers in README, CONTRIBUTING and the chora deed now
state this decision. README's former blanket CC-BY-4.0 sentence is replaced
with the prospective default and a reference to this historical inventory;
its existing MPL-2.0 header is unchanged. The audit evidence and
link:2026-11-06-repository-readiness.adoc[repository-readiness log] record that
the owner response has arrived. This is a policy and documentation correction,
not a claim that every existing file has been relicensed or audited.

=== Retained scope for existing prose without a file-specific notice

The owner response preserves the existing grants. README at
`007d749ec02b3836b45a2183ebbbaf72935c9d91` declares CC-BY-4.0 for prose in
`docs/`, README and roadmap files. Replacing its blanket sentence with a
prospective default does not withdraw that recorded scope from existing prose
where no conflicting file-specific notice or recorded owner decision applies.
Conflicting cases remain in the inventory above rather than being assigned a
new licence by this rule.

Specifically, link:../build.adoc[docs/build.adoc] exists at that baseline without
a file-specific licence notice and falls within its `docs/` declaration.
Its recorded licence remains CC-BY-4.0, supported by `LICENSE-docs`; the new
CC-BY-SA-4.0 default does not silently apply to this existing file. No header
or sidecar is added to it by this change. Missing SPDX metadata and an absent
licence grant are different questions; the former still needs a scoped notice
reconciliation if a per-file record is later added.
