== State preservation and fibres

A state-preserving semantic function `p : A → A` satisfies `∀ s → p s ≡ s`. Such a function has fibres equivalent to identity fibres. The converse requires the fibre comparison to preserve the source projection; unrestricted fibre equivalence forgets which source is attached to which target.

The earlier proposed definition `UniversalCNO p = ∀ s → Echo p s ≃ Echo id s` does *not* characterize state preservation. Boolean negation is an equivalence, has contractible fibres like identity, and changes every Boolean. This is a counterexample to that proposed characterization. The former `CNO-Category-Equivalence` declaration on this page was illustrative prose, not a theorem establishing equivalence with absolute-zero's native certificate.

`EchoSourcePreserving` now proves the source-preserving criterion: preserving `proj₁` as part of the fibre isomorphism yields pointwise identity, and pointwise identity constructs such a fibre isomorphism with both pointwise inverse laws. Its local Agda 2.7.0.1 check passed. This is the corrected characterization for ordinary equality-valued fibres.

== Baseline bridge

At baseline `cd85288dcce55191ad477c0fa7d1d2421514a0d3`, `EchoCNOBridge.agda` imports native `CNO.Program` and `CNO.IsCNO`, but its map is the constant `Program → ⊤`. Its `ProgramEcho _` ignores its program index, and `cno-program-echo p _` ignores the certificate. Every program has this echo witness. Passing native certificates through composition does not by itself connect Echo to execution or state preservation.

A semantic replacement must use the native execution semantics and the `CNO.state-eq` evidence. Merely importing a certificate type does not establish that bridge. The local audit adds `EchoCNOSemantics` and `EchoSourcePreserving`, using same-program certificates, native `CNO.state-eq`, and source-preserving fibre comparisons. Their local Agda 2.7.0.1 checks passed, along with the ordinary CI roots. `CertifiedProgramEcho` binds the provenance witness and certificate to the same program. `NativeNull` and `IsCNO` imply each other within the pinned dependency’s total, zero-energy model; the Nop negative control changes the program counter. `SourcePreservingStateMap` characterizes native nullness through a source-preserving map of relation-valued fibres using `state-eq`. Its record does not assert the two inverse laws of the ordinary `FibreIso` interface. This is a scoped semantic bridge, not a theorem about all operational models.

== Thermodynamic model

`EchoThermodynamics`, `EchoThermodynamicsFinite`, and `EchoThermodynamicsArbitrary` define arithmetic cost functions and prove equations about them under their stated hypotheses. The arbitrary-carrier construction uses decidable occupancy and agrees with finite counting under a subsingleton hypothesis. Its zero-cost conclusion is a model theorem, not a measurement of physical energy or a mechanized proof of physical Landauer/Bennett laws.

`EchoThermoCollapseImpossible` refutes the stated finite-natural count interface under its requirements for arbitrarily large finite subfamilies. It does not refute every possible quantitative treatment of infinite fibres: extended cardinalities, infinity-valued costs, and weaker interfaces are different specifications.

The source files do not establish a Shannon-information preservation theorem, thermodynamic optimality of native CNO execution, or equivalence between all CNO properties and fibre shape. Inhabited fibres alone do not prove termination of an operational program, and singleton fibres alone do not express absence of side effects.

== Runtime boundary

The Agda Holding/Spent cell proves that reading the value returned by `consume` yields `nothing`. The original holding value can be reused or duplicated. This does not enforce affine or linear consumption. There is no checked refinement connecting the Agda model to a Rust or Idris implementation in this audit.
